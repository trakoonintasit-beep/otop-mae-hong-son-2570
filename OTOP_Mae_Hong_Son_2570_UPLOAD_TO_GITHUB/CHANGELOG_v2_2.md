# อัปเดต OTOP Mae Hong Son Digital Catalog v2.2

## สิ่งที่เพิ่ม
1. แสดงจำนวนการเข้าชมเว็บไซต์โดยประมาณจาก Supabase RPC (หนึ่งครั้งต่อเบราว์เซอร์ต่อวันตาม localStorage) ไม่ใช่จำนวนบุคคลที่ไม่ซ้ำ และตัวนับนี้นับเริ่มต้นใหม่เมื่อเปิดใช้งาน SQL ไม่รวมสถิติย้อนหลัง
2. แสดงรูปสินค้าบน **ตัวหมุดแผนที่** พร้อมรูป ราคา และปุ่มเปิดรายละเอียดสินค้าใน Popup และแถบร้านด้านข้าง
3. ปุ่มหมวดด่วน การนำทางมือถือ และตัวช่วยการค้นหา
4. รวม “ของใช้” + “ของที่ระลึก” เป็น **“ของใช้ ของตกแต่ง ของที่ระลึก”** รวมเหลือ 5 หมวด โดยรองรับค่าเดิมจากฐานข้อมูลหรือ localStorage

## ใช้กับ GitHub Pages ที่เผยแพร่แล้ว
1. สำรอง Repository เดิม/สร้าง branch ก่อนแก้ไข
2. แตก ZIP แล้วอัปโหลดไฟล์ใน ZIP ไปยัง root ของ repository: `index.html`, `admin.html`, `assets/`, `data/`, `supabase/` (พร้อมทั้งไฟล์อื่นที่อยู่ใน ZIP); **ห้ามอัปโหลดเป็นโฟลเดอร์ซ้อน**
3. **อย่าเขียนทับ `assets/config.js` ที่มี Supabase URL และ Publishable Key อยู่แล้ว** แพ็กเกจนี้จึงไม่ใส่ `assets/config.js` มาให้; มี `assets/config.js.example` ไว้เป็นตัวอย่างเท่านั้น
4. รอ GitHub Pages Actions สถานะ success แล้ว refresh เว็บ
5. เข้า Supabase Dashboard > SQL Editor รัน `supabase/visitor-counter.sql` เพื่อเปิดนับยอดจากเซิร์ฟเวอร์
6. ตรวจรูปในหมุด แสดง 5 หมวด และปุ่มทางลัดบนมือถือ

## การนับผู้เข้าชม
- เป็นจำนวนการเข้าชม **โดยประมาณ** ไม่ใช่จำนวนคนไม่ซ้ำ ระบบป้องกันการนับซ้ำในเบราว์เซอร์เดียวกันเฉพาะวันปัจจุบัน (ตามวันประเทศไทย)
- อาจนับเพิ่มจากผู้ใช้เปิดคนละเบราว์เซอร์ โหมดส่วนตัว หรือล้างข้อมูลเบราว์เซอร์; ไม่กันบอตหรือการเรียก RPC โดยตรง หากต้องการสถิติที่ตรวจสอบได้ควรใช้ analytics ที่มีระบบป้องกันบอตและจัดทำประกาศความเป็นส่วนตัว
- ถ้าไม่ตั้ง Supabase / RPC จะโชว์ขีด “—” พร้อมแจ้งให้เปิดตั้งค่า **ไม่แสดงยอดปลอม**
- โปรเจกต์ Supabase ที่เชื่อมอยู่ต้องเป็นโปรเจกต์ที่มีสิทธิ์รัน SQL

## แอดมินและข้อมูลเดิม
- เมนูและฟอร์ม Admin ใช้หมวดใหม่; ข้อมูลใน DB ที่ยังเป็น “ของใช้” / “ของที่ระลึก” จะถูกจัดเข้าหมวดใหม่ตอนแสดง โดยไม่แก้ข้อมูลจริงในฐานข้อมูลจนกว่าจะมีการกดบันทึกแก้ไขสินค้า
- ชุดข้อมูลสินค้าใน `data/products.json` เป็นตัวอย่างเท่านั้น และจะไม่ถูกอ่านเมื่อมี Supabase ตั้งค่าครบ
- หน้าจัดการสินค้าใช้ Supabase Auth และ RLS เท่านั้นเมื่อ configured; localStorage เป็นเพียงโหมดสาธิต
- รูปสินค้าในหมุดจะดึงจาก `image` ของสินค้า ผู้ดูแลต้องอัปโหลดภาพที่ได้รับอนุญาตเผยแพร่
