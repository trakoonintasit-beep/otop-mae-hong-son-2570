# คู่มือติดตั้ง OTOP Mae Hong Son Digital Catalog v2.6

## สิ่งที่เพิ่มให้

1. หน้า Admin → **จัดการสินค้า** แสดงการ์ดจำนวนสินค้า **7 อำเภอ** (เมืองแม่ฮ่องสอน, ปาย, ปางมะผ้า, ขุนยวม, แม่ลาน้อย, แม่สะเรียง, สบเมย) และการ์ดรวมทุกอำเภอ
2. กดการ์ดอำเภอหรือเลือกจากเมนูเพื่อกรองสินค้า; แสดงหัวข้อแยกอำเภอในตาราง, ค้นหาชื่อสินค้า และแก้ไข/ลบรายชิ้นได้ตามเดิม
3. เพิ่ม **ส่งออกไฟล์สำหรับ Sheets** และ **นำเข้า CSV ที่แก้แล้ว** เพื่อแก้ไขสินค้าเป็นชุดใน Google Sheets; มีตัวอย่างการเปลี่ยนแปลงก่อนยืนยัน
4. เก็บ Supabase Database เป็นแหล่งข้อมูลหลักและไม่แตะระบบเก็บรูป Google Drive

## ติดตั้งเว็บไซต์ (เฉพาะ 4 ไฟล์)

แตก `OTOP_Mae_Hong_Son_2570_Districts_Sheets_v2_6.zip` และนำ 4 ไฟล์ไปทับตำแหน่งเดิมใน GitHub Repository `trakoonintasit-beep/otop-mae-hong-son-2570`:

- `admin.html`
- `assets/admin.js`
- `assets/district-sheets.css` (ใหม่)
- `assets/sheets-csv.js` (ใหม่)

**ห้าม** อัปโหลดไฟล์ `assets/config.js` เดิมทับ และไม่ต้องสร้างตาราง SQL / Deploy Edge Function เพิ่ม

วิธีใช้ GitHub Codespaces: ลาก ZIP ไปไว้ในโฟลเดอร์ Repository → แตกไฟล์ โดยอยู่ที่ Root แล้วใช้


## แก้ข้อมูลผ่าน Google Sheets (รอบแก้ไขแบบปลอดภัย)

1. เข้า `https://trakoonintasit-beep.github.io/otop-mae-hong-son-2570/admin.html` ล็อกอิน Admin หลักหรือ Admin รองที่ได้รับสิทธิ์จัดการสินค้า
2. หน้า **จัดการสินค้า** → กล่อง **แก้ไขสินค้าหลายรายการผ่าน Google Sheets** → คลิก **ส่งออกไฟล์สำหรับ Sheets**
3. เปิด Google Sheets (`https://sheets.google.com`) สร้าง/เปิดชีตส่วนตัว → **ไฟล์ → นำเข้า → อัปโหลด → เลือก CSV ที่ดาวน์โหลด** โดยเลือกรูปแบบคั่นด้วยจุลภาคและเข้ารหัส UTF-8
4. แก้ไขข้อมูลในแถวเดิม เช่น `district`, `name`, `price`, `description`, `producer`, `shop` โดย **อย่าเปลี่ยน `id` ชื่อหรือลำดับคอลัมน์**
5. ไฟล์ → **ดาวน์โหลด → ค่าที่คั่นด้วยจุลภาค (.csv)** (ดาวน์โหลดชีตปัจจุบันเท่านั้น; ต้องใช้ชีตที่บรรจุตารางสินค้าจริง)
6. กลับหน้า Admin → คลิก **นำเข้า CSV ที่แก้แล้ว** → เลือก CSV → ดูรายการที่เปลี่ยน → ยืนยันสิทธิ์การเผยแพร่ข้อมูล → กด **ยืนยันบันทึกการเปลี่ยนแปลง**
7. เปิดหน้าเว็บไซต์หลักเพื่อตรวจสอบ; หากมีรายการปรับแก้พร้อมกันจาก Admin คนอื่น ระบบจะเตือนก่อนบันทึกเพื่อป้องกันการเขียนทับข้อมูลที่เปลี่ยนไป

### คอลัมน์ที่แก้ไขได้

`district,name,category,price,unit,producer,shop,description,story,address,lat,lng,phone,line,facebook,featured,is_published`

* `id` คือรหัสสินค้า **ห้ามเปลี่ยน**; อัปเดตสินค้าที่มีอยู่แล้วเท่านั้น การลบแถวใน Sheet ไม่ได้ลบสินค้าในฐานข้อมูล; การเพิ่มแถวใหม่จะได้รับข้อความเตือน ให้เพิ่มสินค้าผ่านหน้า Admin
* `featured`, `is_published` ใช้ค่า `TRUE` หรือ `FALSE`
* `district` ใช้ชื่อหนึ่งใน 7 อำเภอให้ตรง
* `lat` และ `lng` ต้องกรอกครบคู่กัน หรือเว้นว่างทั้งคู่
* `image_url_READ_ONLY` **อ่านอย่างเดียว** ระบบนำเข้าจะข้ามคอลัมน์นี้; หากต้องเปลี่ยนภาพ ให้ใช้ฟอร์มแก้ไขสินค้าใน Admin เพื่อรักษาระบบเก็บภาพ Google Drive
* ระบบจะตรวจค่า ขอบเขตข้อมูล รหัสซ้ำและจำนวนคอลัมน์ก่อนบันทึก; การบันทึกเกิดเฉพาะเมื่อ Admin ยืนยัน และยังผ่าน Supabase RLS ตามสิทธิ์เดิม

### ขอบเขตและความปลอดภัย

- ชุด v2.6 นี้เป็น **ซิงก์แบบนำเข้า/ส่งออก CSV ด้วยมือ**: การแก้ใน Google Sheets เพียงอย่างเดียว **ยังไม่อัปเดตเว็บไซต์อัตโนมัติ** จนกว่าจะกดนำเข้าในหน้า Admin
- อย่าตั้ง Google Sheet เป็น **ทุกคนที่มีลิงก์สามารถแก้ไข** เนื่องจากข้อมูลอาจมีเบอร์โทร, ที่อยู่และพิกัดร้านค้า ให้ใช้ Restricted / จำกัด และแชร์เฉพาะเจ้าหน้าที่ที่ได้รับอนุญาต
- ควรสำรอง JSON จาก Admin ก่อนนำเข้าข้อมูลเป็นจำนวนมาก
- หากการบันทึกหลายรายการล้มเหลวกลางทาง อาจมีบางรายการบันทึกแล้ว ระบบจะแจ้งจำนวนที่สำเร็จ โปรดตรวจสอบ/ส่งออกข้อมูลใหม่ก่อนทำซ้ำ
- ไม่มีการอัปโหลด CSV ไปยัง Google Drive หรือ Supabase Storage โดยอัตโนมัติ ตัวไฟล์ CSV ถูกอ่านภายในเบราว์เซอร์ Admin แล้วบันทึกเฉพาะช่องที่เปลี่ยนผ่าน Supabase Auth + RLS

## ตรวจสอบการติดตั้ง

เปิด Admin → จัดการสินค้า → มีการ์ด 7 อำเภอ → คลิกอำเภอปาย: จำนวนนับและตารางเปลี่ยนตามอำเภอ ทดลองส่งออก CSV แก้ราคาหนึ่งรายการ แล้วนำกลับเข้าเว็บไซต์และตรวจสอบข้อมูลสินค้า

## หมายเหตุ

หากต้องการแก้ใน Google Sheets แล้วเว็บเปลี่ยนอัตโนมัติทันที (ไม่ต้องดาวน์โหลด/นำเข้า CSV) จะต้องพัฒนา Google Sheets API + กลไก sync พร้อมตรวจสิทธิ์และจัดการข้อมูลชนกันเพิ่มเติม ซึ่ง **ไม่ได้รวมในชุดนี้**
