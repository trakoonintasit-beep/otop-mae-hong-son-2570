# คู่มือติดตั้ง OTOP Mae Hong Son Digital Catalog 2570 — v2.7 One Page Product Report

**สำหรับ:** สำนักงานพัฒนาชุมชนจังหวัดแม่ฮ่องสอน · Admin หลักและ Admin รองที่ยังมีสิทธิ์ใช้งาน

**วัตถุประสงค์:** สร้างรายงานสินค้า 1 รายการต่อ A4 1 หน้า มีสองเทมเพลต พร้อมปรับสี/คำโปรย เพิ่มข้อมูลเสริมที่ตรวจสอบแล้ว บันทึกข้อมูลส่วนเสริมใน Supabase และสั่งพิมพ์/บันทึก PDF หรือดาวน์โหลด PNG

> ชุดนี้เป็น **ส่วนเสริม** สำหรับ v2.6: ไม่ทับ `admin.html` หรือ `assets/admin.js` ที่ใช้งานจริง จึงรักษาระบบสินค้า, นับจำนวนสินค้า 7 อำเภอ, แก้ไขด้วย Google Sheets (CSV), จัดการ Admin และ Google Drive เดิมไว้

## 1. โครงสร้างรายงาน One Page A4 (แนวตั้ง)

| ตำแหน่ง | เนื้อหา |
|---|---|
| ส่วนหัว | ชื่อสำนักงานพัฒนาชุมชนจังหวัดแม่ฮ่องสอน, OTOP, ชื่อรายงาน |
| ชื่อเรื่อง | ชื่อผลิตภัณฑ์ + คำโปรยจุดเด่น (ถ้ามี) |
| ภาพหลักด้านซ้าย | รูปสินค้าจาก URL ในฐานข้อมูล (Google Drive ผ่าน Edge Function เดิม) |
| ข้อมูลหลักด้านขวา | รหัสสินค้า หมวดหมู่ อำเภอ กลุ่มผู้ผลิต ราคา/หน่วย ขนาด/บรรจุภัณฑ์ |
| สองคอลัมน์กลาง | เรื่องราว, รายละเอียด, จุดเด่น, วัตถุดิบ, วิธีผลิต, ประโยชน์/วิธีใช้, มาตรฐาน/รางวัล, จุดจำหน่าย |
| ส่วนท้าย | สถานะเผยแพร่ วันจัดทำ ชื่อผู้จัดทำ (ถ้ามี) และ QR Code ไปเว็บไซต์ OTOP หรือพิกัดร้าน |

มีรูปแบบให้เลือก 2 แบบ: **A รายงานทางการ** (เรียบหรู เขียวเข้ม) และ **B ประชาสัมพันธ์สินค้า** (สีอุ่น) พร้อมเปลี่ยนสีหลักจากหน้าเครื่องมือ

### ข้อมูลที่ดึงจากฐานข้อมูลสินค้าเดิม (ไม่ต้องกรอกใหม่)

`id`, `name`, `category`, `district`, `price`, `unit`, `producer`, `shop`, `description`, `story`, `address`, `lat`, `lng`, `phone`, `line`, `facebook`, `image`, `featured`, `is_published`

### ข้อมูลที่เพิ่มสำหรับรายงาน (ต้องกรอกตามจริงหากมี)

- หมู่บ้าน, ตำบล
- จุดเด่น, วัตถุดิบ/ส่วนประกอบ, กระบวนการผลิต, ประโยชน์, วิธีใช้/ดูแล
- ขนาด/น้ำหนัก, บรรจุภัณฑ์
- มาตรฐาน/การรับรอง, รางวัล/ผลงาน
- หมายเหตุ, ชื่อผู้จัดทำรายงาน, คำโปรย, สีและแบบรายงาน

ระบบจะ **ไม่คาดเดามาตรฐานหรือรางวัล** หากยังไม่ได้บันทึกจะแสดง “ไม่ระบุข้อมูล” หรือ “ไม่มีข้อมูลมาตรฐานหรือการรับรอง” ไม่ใช่การยืนยันว่าไม่มีจริง

## 2. สำรองข้อมูลก่อนติดตั้ง

ใน GitHub Codespaces เปิดโฟลเดอร์ Repository `otop-mae-hong-son-2570` แล้วตรวจสอบว่างานล่าสุด Commit แล้ว

```bash
git status
```

หากมีงานที่แก้อยู่ ให้สำรอง/Commit งานนั้นก่อน ขั้นตอนต่อไปจะแก้ `admin.html` **เพียงเพิ่ม `<script>` หนึ่งบรรทัด** โดยไม่ทับ HTML เดิม

## 3. ติดตั้ง SQL ใน Supabase **ก่อนอัปโหลดเว็บ**

1. ไปที่ <https://supabase.com/dashboard/project/glzfxtwlqgnybvnbnrpz/sql/new>
2. เลือก **New query**
3. เปิดไฟล์ `supabase/migrations/20261020_product_one_page.sql` ที่อยู่ใน ZIP
4. คัดลอกทั้งหมด วาง แล้วกด **Run** จนขึ้น Success
5. SQL นี้สร้างตาราง `public.otop_product_report_details` เพื่อเก็บ **เฉพาะข้อมูลเพิ่มเติมของรายงาน** โดยใช้รหัส `product_id` เชื่อมกับ `products.id` และตรวจสิทธิ์ Admin ผ่าน RLS

**หาก SQL ขึ้นว่าหา `is_otop_admin()` หรือ `products` ไม่เจอ:** ยังไม่ได้ติดตั้งฐานข้อมูล/ระบบ Admin v2.3 เดิม ต้องติดตั้งของเดิมให้ครบก่อน ห้ามลบตาราง `products`

## 4. เพิ่มไฟล์ v2.7 ใน GitHub Repository

1. แตกหรืออัปโหลด ZIP `OTOP_Mae_Hong_Son_2570_OnePage_v2_7.zip` ไว้ใน **Root** ของ Codespaces ซึ่งมี `admin.html` และ `index.html` อยู่
2. ถ้าอัปโหลด ZIP ไว้ ให้เปิด Terminal แล้วรัน:

```bash
unzip -o OTOP_Mae_Hong_Son_2570_OnePage_v2_7.zip -d .
python3 patch_admin_v27.py
```

คำสั่ง `patch_admin_v27.py` **ไม่ทับหน้า Admin เดิม** แต่เพิ่มตัวเรียก `assets/one-page-launcher.js` ใน HTML เดิมให้ หากรันซ้ำจะไม่เพิ่มซ้ำ

3. ตรวจไฟล์เปลี่ยนแปลงและ Commit:

```bash
git status --short
git add admin.html report.html assets/one-page-report.css assets/one-page-report.js assets/one-page-launcher.js supabase/migrations/20261020_product_one_page.sql patch_admin_v27.py README_ONE_PAGE_v2_7_TH.md
git commit -m "Add OTOP One Page A4 PDF PNG report editor v2.7"
git push origin main
```

**ห้ามนำ `assets/config.js` ใหม่จากที่อื่นมาทับ**, ไม่ต้องแก้ Google Apps Script, ไม่ต้องตั้ง Secret เพิ่มหรือ Deploy Edge Function ใหม่ เมื่อ Google Drive เดิมแสดงภาพสินค้าได้อยู่แล้ว

## 5. เปิดใช้งาน

- เข้า <https://trakoonintasit-beep.github.io/otop-mae-hong-son-2570/admin.html>
- เข้าระบบ Admin หลักหรือ Admin รอง
- หน้า **จัดการสินค้า** จะมีปุ่ม **“📄 One Page รายงานสินค้า”** ในแถบเครื่องมือ และปุ่ม **“One Page”** ในแถวรายการสินค้าทุกชิ้น
- หากกดปุ่มในแถวสินค้า ระบบจะเปิด `report.html?id=รหัสสินค้า` ให้ทันที
- หน้ารายงานสามารถเลือกอำเภอ ค้นหาสินค้า และเปลี่ยนรายการได้เอง
- เพิ่มข้อมูลใหม่ในฟอร์มด้านซ้าย แล้วกด **บันทึกข้อมูล One Page**
- เลือกเทมเพลต สี และตัวอักษรก่อนส่งออก

### ส่งออก PDF

กด **พิมพ์ / บันทึก PDF** → Chrome เปิดหน้าพิมพ์ → ปลายทาง **บันทึกเป็น PDF** → ขนาดกระดาษ **A4** และเปิด **กราฟิกพื้นหลัง (Background graphics)** ถ้ามีตัวเลือก → บันทึกไฟล์ โดยระบบสร้างหน้า A4 เดียวจากข้อมูลที่แสดง (ถ้าข้อความยาวจนเกินหน้า จะให้ย่อข้อความก่อน)

### ส่งออก PNG

กด **ดาวน์โหลด PNG** → ระบบใช้ html-to-image ผ่าน jsDelivr ในเบราว์เซอร์ หากรูป Google Drive/Proxy โหลดไม่ได้หรือ CORS ผิดพลาดจะไม่สามารถสร้าง PNG; ให้ใช้ PDF แทนและตรวจ `otop-drive-image` ก่อน

### ข้อมูลติดต่อและความเป็นส่วนตัว

เลือก **แสดงเบอร์โทรและช่องทางติดต่อในรายงาน** ได้ แต่ต้องติ๊กยืนยันว่าได้รับอนุญาตให้เผยแพร่ก่อนกด PDF หรือ PNG รายงานที่มีข้อมูลติดต่อควรจัดเก็บในที่จำกัดและส่งต่อเฉพาะผู้เกี่ยวข้อง

## 6. ข้อจำกัดสำคัญ

- ใช้ **Supabase Auth** ที่มีอยู่แล้ว ระบบผู้เข้าชมสาธารณะเปิด `report.html` ไม่ได้แม้จะรู้ URL เพราะมีการตรวจสมาชิก Admin ที่ยังใช้งานอยู่ก่อนดึงข้อมูล
- RLS ของตารางเสริมจำกัดการอ่าน/เขียนเฉพาะ Admin ที่ยังใช้งานอยู่
- เนื้อหายาวมากอาจไม่พอดี A4 หนึ่งหน้า ระบบย่อข้อความตามสมควรและแจ้งให้แก้ไขหากยังล้น ไม่ตัดข้อความเงียบ ๆ
- กรณีไม่มีภาพสินค้าหรือ Edge Function แสดงภาพไม่พร้อม ระบบจะเตือน ไม่รับประกัน PNG/PDF ที่ภาพไม่ครบ
- PNG อาศัย CDN `html-to-image` เพิ่มเติมจากระบบเดิม; หากเครือข่ายบล็อก CDN ต้องเปิดอินเทอร์เน็ตให้เข้าถึงได้
- เมนูนี้ **ไม่แก้ข้อมูลสินค้าเดิม ไม่ย้ายและไม่ลบภาพใน Google Drive**; ช่องเสริมแยกคนละตาราง
- รายงานนี้ไม่ได้รับรองสถานะ OPC/OTOP 5 ดาว หรือรางวัลใด ๆ โดยอัตโนมัติ ผู้จัดทำต้องตรวจสอบข้อมูลก่อนเผยแพร่
- หากหลายคนแก้ส่วนเสริมสินค้าเดียวกันพร้อมกัน การบันทึกล่าสุดอาจทับค่าก่อนหน้า ควรแบ่งผู้รับผิดชอบรายอำเภอ/รายสินค้า
- ไม่ได้ทดสอบการบันทึกกับ Supabase ของบัญชีคุณจริงจนกว่าจะติดตั้ง SQL; ภาพหน้าจอตัวอย่างในชุดส่งมอบใช้ข้อมูลจำลองเพื่อออกแบบเท่านั้น
